# Driving Theory Study

This context covers the learning material used to prepare for the German Class B driving-theory examination.

## Language

**Theory question**:
A Class B examination-style question in the repository's question bank, including its possible answers and correct response.
_Avoid_: Quiz item, exercise

**Chapter summary**:
The source study material for one numbered theory chapter, stored in that chapter's `summary.md` file.
_Avoid_: Full summary, complete guide

**Class B Theory Study Guide**:
The concise, consolidated learning document that combines the chapter summaries and fills any question-bank coverage gaps.
_Avoid_: Master summary, combined summary

**Question coverage**:
The condition in which the Class B Theory Study Guide explains enough rules and recognition cues to determine the correct response to every theory question when the question's own media is available. The guide itself does not reproduce media.
_Avoid_: Mentioning every question, copying the question bank
